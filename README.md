# プロ投資家の視点 日米株アナライザー

著名な6人の投資家の考え方を物差しにして、日本株と米国株を分析する学習用のアプリです。自分の分析を整理し、プロの視点を学ぶために使います。

- ウォーレン・バフェット
- ピーター・リンチ
- ベンジャミン・グレアム
- フィリップ・フィッシャー
- ジョエル・グリーンブラット
- ウィリアム・オニール

画面には、「銘柄分析」「比較・ウォッチリスト」「保有・点検」「投資家の教え」「使い方・データ」の5つのタブがあります。

## ファイル

| ファイル | 中身 |
|---|---|
| [プロ投資家の視点_日米株アナライザー.html](プロ投資家の視点_日米株アナライザー.html) | 分析アプリ本体 |
| [server.py](server.py) | 銘柄の検索とデータの取得をする、小さなプログラム（自分のPCの中だけで動きます） |
| [アプリを起動.bat](アプリを起動.bat) | Windowsで、プログラムを起動してアプリを開くためのファイル |

## 使い方（Windows）

1. 必要なもの
   - Python 3（[python.org](https://www.python.org/downloads/) からインストール。インストールの画面で「Add python.exe to PATH」をオンにします）
   - インターネット接続
2. 3つのファイルを、同じフォルダに保存します。
3. 「アプリを起動.bat」をダブルクリックします。黒い画面が開き、続いてブラウザでアプリが開きます。
   - 初めての起動では、必要なライブラリ（yfinance・pandas・openpyxl）のインストールを確認します。「Y」を押すと自動でインストールします。
   - 東証の上場銘柄の一覧（日本取引所グループの公開データ）を自動で取得し、このPCの中に保存します（`%LOCALAPPDATA%\ProInvestorAnalyzer`）。
4. 検索窓に、証券コード（例：7203）、ティッカー（例：AAPL）、社名やブランド名を入れて、銘柄を選びます。
5. 使い終わったら、黒い画面を閉じます。

MacやLinuxでは、フォルダの中で `python3 server.py` を実行すると起動できます（動作はWindowsで確かめています）。

HTMLファイルだけを開いた場合（ブラウザで直接開いた場合を含む）は、銘柄の検索とデータの自動取得は使えません。決算短信や有価証券報告書の数字を手で入力するか、CSVを読み込んで分析できます。

## データについて

- 株価・業績・財務のデータは、使う人のPCが Yahoo Finance から取得します（yfinance を利用）。無料のデータのため、遅れや誤りがあることがあります。個人の利用を前提としたデータなので、取得したデータを再配布しないでください。
- このリポジトリには、市場のデータは含まれていません。
- プログラムは自分のPC（127.0.0.1）の中だけで動き、外からはアクセスできません。
